# 05 — PEOPLE
## HR · Hiring · Performance · Team Communication · Culture

**Enter-Game Skills · April 2026**

> HR functions represent one of the top enterprise AI use cases
> (Gartner 2026). Resume screening, interview prep, and performance
> documentation are among the highest-volume repetitive tasks in the function.

---

## USAGE RANK: #3 for HR professionals, #2 for managers with direct reports

---

## SKILLS / COMPÉTENCES

---

### JOB-POST — Write a job posting

**Command:**
```
job-post: [role title] · [team / department] · [key responsibilities: 3–5] · [must-haves] · [tone: startup / corporate / technical]
```

**Output:** Full job posting with: role overview, responsibilities, requirements (must-have vs nice-to-have), what you offer, application instructions.

---

### INTERVIEW-PREP — Prepare interview questions

**Command:**
```
interview-prep: [role] · [seniority level] · [focus areas: technical / behavioral / culture / leadership]
```

**Output:** 15–20 interview questions with:
- What each question reveals
- Red flags to watch for
- Follow-up probes

---

### FEEDBACK — Write performance feedback

**Command:**
```
feedback: [person's role] · [what went well: specific examples] · [areas to develop: specific examples] · [tone: formal review / casual check-in]
```

**Output:** Balanced performance feedback — specific, actionable, non-punitive. Includes development suggestions.

---

### PIP — Write a performance improvement plan

**Command:**
```
pip: [role] · [performance gap: specific behaviors / outcomes] · [timeline] · [support offered]
```

**Output:** PIP with clear expectations, measurable milestones, check-in schedule, and consequences. Legally careful language.

---

### OFFER-LETTER — Draft an offer letter

**Command:**
```
offer-letter: [role] · [compensation package: salary, equity, benefits] · [start date] · [company name] · [tone: warm / standard]
```

**Output:** Professional offer letter. Note: verify with legal/HR for jurisdiction-specific requirements.

---

### TEAM-NORMS — Write team working norms

**Command:**
```
team-norms: [team size] · [work mode: remote / hybrid / in-person] · [values: what matters to this team] · [pain points to address]
```

**Output:** Team norms document covering: communication, meetings, decision-making, feedback, availability, escalation paths.

---

### 1-ON-1 — Prepare a 1:1 agenda

**Command:**
```
1on1: [direct report's role] · [recent context: project, challenges, wins] · [topics to cover]
```

**Output:** 1:1 agenda with time allocations, check-in questions, and coaching prompts.

---

### RECOGNITION — Write a recognition message

**Command:**
```
recognition: [person's name / role] · [what they did] · [impact it had] · [audience: public / private / team]
```

**Output:** Recognition message calibrated to audience. Specific, meaningful, not generic.

---

### CULTURE-DOC — Write culture documentation

**Command:**
```
culture-doc: [company name] · [values: list them] · [what you want people to understand about how you work]
```

**Output:** Culture document with values explained through behaviors — what it looks like in practice, not just platitudes.
