## SKILLS / COMPÉTENCES

---

### OUTREACH — Write cold outreach

**Command:**
```
outreach: [prospect: role / company / context] · [your offer] · [angle: pain point / opportunity / referral] · [channel: email / LinkedIn]
```

**Output:** Personalized outreach message. Short, specific, one clear CTA. Not a pitch — an opener.

---

### FOLLOW-UP — Write a follow-up message

**Command:**
```
follow-up: [context: what happened before] · [time since last contact] · [what you want next]
```

**Output:** Follow-up that doesn't feel like a chase. Adds value or provides a new angle.

---

### PROPOSAL — Write a sales proposal

**Command:**
```
sales-proposal: [prospect company] · [their problem] · [your solution] · [pricing / scope] · [desired outcome: sign / meeting / approval]
```

**Output:** Professional proposal with: executive summary, problem statement, proposed solution, investment, next steps.

---

### TICKET-RESPONSE — Respond to a support ticket

**Command:**
```
ticket: [customer issue: paste or describe] · [resolution: what you want to communicate] · [tone: empathetic / technical / escalation]
```

**Output:** Customer response that's clear, empathetic, and actionable. Includes next steps.

---

### ESCALATION — Write an escalation response

**Command:**
```
escalation: [customer issue] · [what's been tried] · [what you can offer] · [what you can't]
```

**Output:** De-escalation response that acknowledges frustration, owns what's ownable, and proposes a path forward.

---

### CUSTOMER-SUCCESS — Write a customer check-in

**Command:**
```
cs-checkin: [customer name / context] · [product / service they use] · [what you know about their current state] · [goal of the check-in]
```

**Output:** Customer success check-in message — proactive, value-adding, not just "checking in."

---

### CASE-STUDY — Write a customer case study

**Command:**
```
case-study: [customer company] · [their challenge before] · [solution implemented] · [results / outcomes] · [length: short / standard / full]
```

**Output:** Case study with: headline, challenge, solution, results (with numbers), quote placeholder, CTA.

---

### BATTLECARD — Write a competitive battlecard

**Command:**
```
battlecard: [competitor name] · [your product] · [key differentiators] · [their strengths] · [common objections]
```

**Output:** One-page battlecard for sales reps: their pitch vs your counter, win themes, objection handling.

---

### OBJECTION — Handle a sales objection

**Command:**
```
objection: [the objection: exact words if possible] · [context: deal stage, prospect type, what you know]
```

**Output:** Response framework for the objection: acknowledge → reframe → evidence → next step.

---

### CRM-NOTE — Write a CRM note after a call

**Command:**
```
crm-note: [call summary in rough notes] · [outcome] · [next steps agreed]
```

**Output:** Clean CRM note with: summary, sentiment, commitments made, next actions with owners and dates.
