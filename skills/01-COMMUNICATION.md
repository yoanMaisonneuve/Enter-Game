## SKILLS / COMPÉTENCES

---

### EMAIL-DRAFT — Draft an email

**Command:**
```
email-draft: [destinataire/role] · [sujet] · [ton: formel/direct/friendly] · [contexte en 1–2 lignes]
```

**Example / Exemple:**
```
email-draft: VP Marketing · proposition partenariat · formel · on veut co-marketer notre lancement Q2 avec leur audience B2B
```

**Output:** Full email ready to send. Subject line included.

**When to use:** Any time you need to write a professional email and don't want to start from a blank page. Especially useful for difficult conversations, cold outreach, and cross-department communication.

**Template:**
```
email-draft: [To: role or name] · [Subject: what this is about] · [Tone: formel / direct / warm] · [Context: 1–2 lines of what you want to achieve]
```

---

### EMAIL-REPLY — Reply to an email

**Command:**
```
email-reply: [paste the email] · [ton intent: accept / decline / ask for more info / propose alternative]
```

**Output:** Draft reply, same language as the original.

**When to use:** Replying to complex emails where you're not sure of the right tone, declining requests diplomatically, or responding to urgent escalations.

---

### EMAIL-TRIAGE — Triage and categorize inbox

**Command:**
```
inbox: [paste list of email subjects + senders, or describe the inbox state]
```

**Output:** Prioritized list — urgent / important / can wait / can delete. Suggested actions for top 5.

**When to use:** Monday morning inbox overload. Return from vacation. Any time the inbox has > 20 unread items.

---

### MEETING-SUMMARY — Summarize a meeting

**Command:**
```
meeting-summary: [paste notes or transcript] · [context: what project, who attended]
```

**Output:**
- What was decided (bullet list)
- Action items with owners and due dates
- Open questions
- One-paragraph executive summary

**When to use:** After every meeting. Takes the notes you took in real-time and turns them into a shareable summary in 30 seconds.

**Template:**
```
meeting-summary:
[Date]: [YYYY-MM-DD]
[Attendees]: [names / roles]
[Context]: [project name, meeting type]
[Notes]:
[paste raw notes here]
```

---

### MEETING-PREP — Prepare for a meeting

**Command:**
```
meeting-prep: [meeting type] · [attendees / their roles] · [goal of the meeting] · [context]
```

**Output:**
- Suggested agenda with time allocations
- Key questions to ask
- Background briefing on attendees (if known)
- Pre-meeting risks and how to handle them

**When to use:** Before any important meeting — investor, client, cross-functional alignment, performance review.

---

### MEETING-AGENDA — Create a meeting agenda

**Command:**
```
meeting-agenda: [objectif de la réunion] · [durée: X min] · [participants: roles] · [points à couvrir]
```

**Output:** Formatted agenda with time slots, facilitator notes, expected outputs per section.

---

### WRITE-REPORT — Write a report or document

**Command:**
```
write-report: [sujet] · [audience: qui lit ça] · [longueur: court / moyen / complet] · [contexte]
```

**Output:** Structured report with introduction, sections, and conclusion. Tone matched to audience.

**When to use:** Project status reports, post-mortems, proposals, executive summaries, research briefs.

---

### WRITE-PROPOSAL — Write a proposal

**Command:**
```
write-proposal: [what you're proposing] · [to whom] · [what you want them to do] · [key supporting points]
```

**Output:** Professional proposal document with executive summary, rationale, requested action, next steps.

---

### REWRITE — Improve existing text

**Command:**
```
rewrite: [paste text] · [goal: clearer / shorter / more professional / less formal / stronger CTA]
```

**Output:** Improved version of the text. Changes explained briefly if significant.

**When to use:** Any time you've written something but feel it's not landing right.

---

### TRANSLATE — Translate with context

**Command:**
```
translate: [paste text] · [from: language] · [to: language] · [tone: formel / casual]
```

**Output:** Translation with tone preserved. Not just word-for-word — culturally appropriate.

---

### SLACK-MESSAGE — Draft a Slack / Teams message

**Command:**
```
slack: [channel / audience] · [message in 2–3 lines max] · [tone: casual / urgent / informational]
```

**Output:** Message ready to paste. Appropriate length for the channel type.

---

### ANNOUNCEMENT — Write an internal announcement

**Command:**
```
announcement: [what's being announced] · [audience: all-company / team / department] · [tone] · [key details]
```

**Output:** Announcement text with subject line, body, and call to action if needed.
