## SKILLS / COMPÉTENCES

---

### FINANCIAL-REPORT — Write a financial summary

**Command:**
```
financial-report: [period: Q1 / monthly / annual] · [key numbers: revenue, costs, margin, burn] · [audience: board / team / investor]
```

**Output:** Financial summary with narrative — not just numbers, but what they mean and what actions follow.

---

### BUDGET — Build or analyze a budget

**Command:**
```
budget: [period] · [categories: list with amounts] · [goal: review existing / create new / find cuts]
```

**Output:** Structured budget with categories, totals, and flags for unusual items. Recommendations if asked.

---

### FORECAST — Write a business forecast

**Command:**
```
forecast: [metric: revenue / users / costs] · [current state] · [assumptions] · [horizon: 3mo / 6mo / 1yr]
```

**Output:** Forecast with base / upside / downside scenarios. Assumptions made explicit. Key drivers identified.

---

### EXPENSE-POLICY — Write an expense policy

**Command:**
```
expense-policy: [company size] · [categories: travel / meals / equipment / etc.] · [limits if known] · [approval flow]
```

**Output:** Clear expense policy document with limits per category, approval requirements, reimbursement process.

---

### PROCESS-DOC — Document a business process

**Command:**
```
process-doc: [process name] · [steps: describe in rough order] · [who does what] · [exceptions to handle]
```

**Output:** Process documentation with: flow overview, step-by-step with owners, decision points, exceptions, escalation path.

---

### SOP — Write a standard operating procedure

**Command:**
```
sop: [procedure name] · [context: when is this triggered] · [steps] · [who executes] · [what can go wrong]
```

**Output:** SOP with numbered steps, decision trees for exceptions, verification checkpoints.

---

### COMPLIANCE-CHECK — Check for compliance issues

**Command:**
```
compliance: [document or process to check] · [framework: GDPR / SOC2 / ISO27001 / local regulations] · [context]
```

**Output:** Compliance review with: issues found (severity), what's missing, recommended actions. Note: not legal advice.

---

### VENDOR-REVIEW — Evaluate a vendor or contract

**Command:**
```
vendor-review: [vendor name] · [what they provide] · [contract terms: paste or describe] · [evaluation criteria]
```

**Output:** Vendor assessment with: risk flags, cost analysis, comparison to alternatives, recommendation.

---

### CHANGE-MGMT — Write a change management plan

**Command:**
```
change-mgmt: [what's changing] · [who's affected] · [timeline] · [risks] · [communication needed]
```

**Output:** Change management plan with: stakeholder map, communication cadence, training needs, rollback triggers.

---

### AUDIT-PREP — Prepare for an audit

**Command:**
```
audit-prep: [audit type: financial / security / operational] · [scope] · [timeline] · [what you know will be checked]
```

**Output:** Audit preparation checklist with: documentation needed, common findings in this audit type, gaps to address before the auditor arrives.
