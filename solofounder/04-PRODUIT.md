# 04 — PRODUIT
## Roadmap · Specs · UX · User Research · Prioritization

**Enter-Game Solofounder · April 2026**

> Your product is your most expensive asset.
> What you build next determines everything.

---

## SKILLS / COMPÉTENCES

---

### SPEC — Write a product spec / PRD

**Command:**
```
spec: [feature name] · [problem it solves] · [who asks for it] · [success criteria] · [constraints]
```
**Output:** PRD with: problem, solution, scope, non-goals, success metrics, edge cases, open questions.

---

### ROADMAP — Build or update roadmap

**Command:**
```
roadmap-produit: [stage: early / growth / mature] · [known items] · [strategic direction this quarter]
```
**Output:** Now/Next/Later roadmap with rationale. What's explicitly not in scope.

---

### USER-INTERVIEW — Run a user interview

**Command:**
```
user-interview: [user type] · [what you want to learn] · [current assumptions to test]
```
**Output:** Interview guide with 8–10 questions. What good vs bad answers look like.

---

### FEEDBACK-SYNTHESIS — Synthesize user feedback

**Command:**
```
feedback-synthesis: [paste feedback: support tickets, NPS comments, interview notes, reviews]
```
**Output:** Themes ranked by frequency × impact. Top 3 actionable insights. What to build next.

---

### PRIORITIZE — Prioritize the backlog

**Command:**
```
prioritize-backlog: [paste list of features/bugs] · [framework: RICE / ICE / impact-effort]
```
**Output:** Prioritized list with scores and recommendation. What to cut.

---

### UX-COPY — Write UX copy

**Command:**
```
ux-copy: [screen or component] · [user action / state: empty / error / success / onboarding] · [tone]
```
**Output:** Microcopy for the specified state. Button labels, error messages, empty states, tooltips.

---

### ONBOARDING-FLOW — Design onboarding flow

**Command:**
```
onboarding-flow: [product] · [user goal on day 1] · [current steps] · [drop-off point if known]
```
**Output:** Recommended onboarding flow with: steps, copy, success moment (aha moment), friction to remove.

---

## QUICK REFERENCE

```
spec               → PRD / feature spec
roadmap-produit    → Now/Next/Later roadmap
user-interview     → interview guide
feedback-synthesis → themes from user feedback
prioritize-backlog → ranked backlog
ux-copy            → microcopy by state
onboarding-flow    → onboarding design
```
