## HOW TO USE THIS FOLDER / COMMENT UTILISER CE DOSSIER

**Option 1 — By urgency**
Today you need to write a proposal? → `02-VENTES.md`
Today you need to fix a support issue? → `09-SUPPORT.md`
Today you need to plan the quarter? → `01-CEO.md`

**Option 2 — Weekly rotation**
Monday: CEO + Planning
Tuesday–Thursday: Produit + Tech (execution days)
Friday: Marketing + Distribution
End of week: Finance + Admin (30 min)

**Option 3 — By phase**
Pre-product: 01-CEO + 04-PRODUIT + 05-TECH dominate
Pre-revenue: 02-VENTES + 08-DISTRIBUTION come online
Revenue stage: 03-MARKETING + 09-SUPPORT become critical
Scale stage: 06-OPERATIONS + 07-FINANCE need systematic attention

## THE SOLO FOUNDER EDGE / L'AVANTAGE DU SOLO FOUNDER

A team of 10 has coordination overhead: meetings, alignment, handoffs, misunderstandings.
A solo founder has none of that.

With AI as co-founder, you run every department at 70% of a specialist's quality — but with 0% coordination overhead, 100% context retention, and decisions in minutes instead of days.

The math works.

**What you sacrifice:** depth per domain
**What you gain:** speed, coherence, and compounding

The solo founder who uses this library doesn't need to become an expert in sales, marketing, finance, or ops. They need to produce *good enough* output in each domain, fast enough that momentum never dies.

That's what this folder enables.
