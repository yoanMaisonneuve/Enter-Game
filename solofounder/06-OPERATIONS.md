# 06 — OPÉRATIONS / APPROVISIONNEMENT
## Vendors · Tools · Processes · Procurement · Admin · Legal

**Enter-Game Solofounder · April 2026**

> Operations is the function nobody thinks about
> until something breaks or costs too much.
> As solo founder, 30 minutes a week here prevents 30 hours of crisis.

---

## SKILLS / COMPÉTENCES

---

### TOOL-STACK — Audit your tool stack

**Command:**
```
tool-stack: [list all tools you pay for + monthly cost] · [what each does] · [team size: solo]
```
**Output:** Stack audit with: redundancies, underused tools, cost optimization, recommended cuts or consolidations.

---

### VENDOR-EVAL — Evaluate a vendor or supplier

**Command:**
```
vendor-eval: [vendor name + what they provide] · [alternatives] · [your criteria: cost / reliability / support / integration]
```
**Output:** Vendor assessment with comparison, risks, recommendation, negotiation points.

---

### CONTRACT-REVIEW — Review a contract

**Command:**
```
contract-review: [paste or describe contract terms] · [what you want to understand] · [red flags to look for]
```
**Output:** Contract review with: key terms summarized, unusual clauses flagged, risks highlighted, suggested modifications. Note: not legal advice — verify with a lawyer for significant contracts.

---

### PROCESS — Document a process

**Command:**
```
process: [process name] · [steps in rough order] · [who does what (solo = all you)] · [exceptions]
```
**Output:** Process document — step-by-step, decision points, edge cases. So you don't have to reinvent it each time.

---

### AUTOMATE — Find automation opportunities

**Command:**
```
automate: [describe a repetitive task you do manually] · [frequency] · [current time it takes]
```
**Output:** Automation options ranked by: implementation effort, time saved, tools needed, reliability. With setup instructions for the top option.

---

### LEGAL-BASICS — Basic legal document

**Command:**
```
legal: [document type: NDA / freelancer contract / terms of service / privacy policy] · [context: jurisdiction, what it covers]
```
**Output:** Draft document. Note: have a lawyer review before using for significant engagements or public-facing docs.

---

### PROCUREMENT — Research and buy something

**Command:**
```
procurement: [what you need to buy] · [budget] · [criteria] · [alternatives to evaluate]
```
**Output:** Procurement brief with: options compared, recommended choice, where to buy, estimated cost.
